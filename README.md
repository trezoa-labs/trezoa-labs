## ⚛️ About Trezoa Labs

**Trezoa Labs** is building **TrezoaChain** — the first Layer-1 blockchain with native post-quantum cryptography, engineered from the ground up to be secure against both classical and quantum attacks.

> *Every major blockchain today uses ECDSA — an algorithm that quantum computers will break. We built TrezoaChain so you never have to worry about that.*

---

## 🔐 What We're Building

<div align="center">

| Layer | Technology |
|:---|:---|
| ⚛️ **Cryptography** | CRYSTALS-Kyber (FIPS 203) + CRYSTALS-Dilithium (FIPS 204) |
| ⚡ **Performance** | 50,000+ TPS · Sub-second finality · Sub-cent fees |
| 🦀 **Smart Contracts** | Rust · Memory-safe · Formally verified |
| ⏰ **Automation** | Native on-chain scheduler — no external keepers |
| 🔗 **Interop** | EVM bridge · Cross-chain messaging |
| 🌐 **Network** | Quantum-resistant P2P layer |
